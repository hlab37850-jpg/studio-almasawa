# تشغيل توليد الفيديو عبر GitHub Actions وKaggle GPU

## ما يفعله هذا المسار
1. تبدأ التشغيل يدويًا من GitHub Actions.
2. يرسل GitHub دفتر Kaggle خاصًا إلى حسابك.
3. ينفذ دفتر Kaggle نموذج Wan2.1 T2V-1.3B على GPU مجاني متاح لحسابك.
4. يعيد ملف MP4 وتقرير التوليد إلى GitHub Actions Artifacts.
5. يفحص GitHub وجود فيديو H.264 ومدته باستخدام ffprobe قبل رفع Artifact.

هذا أول مسار إثبات تشغيل لإنتاج **مقطع فيديو حقيقي مولّد بالنموذج (المستوى A)**. لا يتضمن بعد التعليق الصوتي العربي أو الكابشن المتزامن أو تجميع المشاهد المتعددة؛ لا تعتبره النسخة النهائية من خط الإنتاج.

## حالة التفعيل على GitHub
ملف Workflow محفوظ حاليًا على فرع التطوير `feature/arabic-video-pipeline` فقط. تشترط GitHub وجود ملف `workflow_dispatch` على الفرع الافتراضي حتى يظهر زر التشغيل اليدوي؛ لذلك لن يظهر زر التشغيل في المستودع قبل وصول هذا الملف إلى الفرع الافتراضي. لم أغيّر `main` ولم أدمج العمل، التزامًا بخطة المراجعة وعدم الدمج قبل اكتمال المشروع.

## إعداد Kaggle مرة واحدة
1. أنشئ/استخدم حساب Kaggle، وفعّل الوصول إلى GPU من إعدادات Notebook إذا طلب الموقع ذلك.
2. أنشئ Kaggle API Token من إعدادات الحساب.
3. في مستودع GitHub افتح Settings → Secrets and variables → Actions.
4. أضف سرين:
   - `KAGGLE_USERNAME`: اسم مستخدم Kaggle.
   - `KAGGLE_KEY`: قيمة مفتاح Kaggle API.
5. لا تضع المفتاح في ملفات المشروع أو الرسائل أو commits.

## تشغيل فيديو
1. افتح تبويب Actions في المستودع.
2. اختر **Generate AI Video (Kaggle GPU)**.
3. اضغط Run workflow.
4. أدخل وصفًا بصريًا باللغة الإنجليزية واختر 9:16 أو 16:9.
5. بعد نجاح التشغيل، افتح Artifacts في صفحة التشغيل ونزّل `studio-almasawa-ai-video`.

## النموذج والقيود
- النموذج: `Wan-AI/Wan2.1-T2V-1.3B-Diffusers`.
- بطاقة النموذج تعلن ترخيص Apache-2.0 واحتياجًا يقارب 8.19GB VRAM للنموذج الأصلي؛ الأداء الفعلي يعتمد على GPU المتاح ونسخة Diffusers.
- Kaggle يتيح GPU مجانيًا عند توفر الحصة والموارد، لكنه قد يضع المستخدم في قائمة انتظار أو لا يخصص GPU في وقت الذروة. لا يوجد ضمان توفر دائم.
- مدة التنفيذ محدودة بمهلة GitHub Actions وبحدود جلسة Kaggle.
- يرفع GitHub Artifact لمدة 3 أيام لتقليل استهلاك التخزين.
- هذا المسار لا يستخدم خدمة توليد فيديو مدفوعة، لكنه يتطلب حساب Kaggle ومفتاح API مجانيًا محفوظًا في GitHub Secrets.

## استكشاف الأخطاء
- فشل التحقق من الأسرار: تأكد من وجود الاسمين أعلاه دون مسافات زائدة.
- فشل Kaggle API: راجع صلاحية API Token واسم المستخدم.
- فشل GPU: فعّل GPU في إعدادات Kaggle أو انتظر توفر الحصة.
- نفاد الذاكرة: أعد المحاولة عند توفر GPU مناسب؛ لا يبدّل النظام تلقائيًا إلى صور متحركة ويصفها بأنها فيديو AI.
- لا يوجد MP4 أو فشل ffprobe: التشغيل فاشل، ولا يعتبر التوليد مكتملًا.
