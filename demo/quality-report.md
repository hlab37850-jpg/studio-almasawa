# تقرير جودة أولي — خط إنتاج الفيديو العربي

**الحالة:** أُضيف هيكل أولي لإرسال مهمة توليد فيديو حقيقي إلى Kaggle GPU عبر GitHub Actions. لم يبدأ التوليد أو البناء الفعلي بعد.

## ما تم التحقق منه
- المستودع كان فارغًا عند بدء العمل باستثناء AGENTS.md الذي أضيف سابقًا.
- الفرع الحالي: feature/arabic-video-pipeline.
- تمت مراجعة مصادر عامة للأدوات والتراخيص، وتوثيق القرارات الأولية في docs/tool-selection.md.
- أضيف pronunciation.md وstyle.md كبداية قابلة للمراجعة.

## ما لم يمكن تنفيذه من جلسة GitHub الحالية
لا تتوفر لهذه الجلسة طرفية Codex أو shell داخل جهاز المستخدم؛ أدوات GitHub المتاحة تسمح بقراءة وكتابة ملفات المستودع فقط. لذلك لم أتمكن من تشغيل:
- nvidia-smi أو التحقق من وجود GPU وVRAM وCUDA.
- اختبار اتصال الشبكة من بيئة التنفيذ.
- فحص إصدارات Python/Node/FFmpeg/ffprobe أو مساحة القرص.
- تثبيت edge-tts أو توليد عينات صوت عربية.
- تشغيل Wan أو FLUX أو SDXL أو أي نموذج محلي.
- تشغيل Remotion أو FFmpeg أو اختبارات أو إنتاج MP4.

هذه قيود بيئة الوصول وليست نتيجة فشل في جهاز المستخدم. لم أفترض وجود GPU أو شبكة أو حزم مثبتة.

## تكامل GitHub → Kaggle الذي أُضيف
- `.github/workflows/generate-video.yml`: تشغيل يدوي يرسل دفتر Kaggle وينتظر النتيجة ثم يفحص MP4 بـ ffprobe ويرفعه كـ Artifact لمدة 3 أيام.
- `kaggle/wan-run/wan_video.ipynb`: دفتر يستخدم Wan2.1 T2V-1.3B لتوليد مقطع فعلي قصير، بمقاس 9:16 أو 16:9.
- `scripts/prepare_kaggle_kernel.py`: يحقن prompt المستخدم في الدفتر ويجهز بيانات Kaggle الخاصة.
- `docs/github-kaggle-setup.md`: خطوات إعداد الحساب والأسرار والقيود.
- تم استرجاع الملفات من GitHub والتحقق من سلامة JSON لدفتر Jupyter.
- لم يتم تشغيل Kaggle CLI أو إرسال Notebook أو توليد MP4؛ أسرار Kaggle غير مضافة، وGPU والحصة غير متحققين.
- Workflow محفوظ في فرع التطوير فقط. GitHub يشترط وجود `workflow_dispatch` على الفرع الافتراضي لإظهار زر التشغيل اليدوي؛ لم أغيّر `main` ولم أنشئ PR قبل اكتمال العمل.

## نتائج الصوت والفيديو
- مزود الصوت: لم يُختبر بعد؛ edge-tts مرشح أولي فقط.
- الصوت/اللهجة/المطابقة بـ Whisper: لا توجد عينات أو قياسات.
- الجهارة: غير مقاسة.
- مستوى توليد اللقطات: لم يتم اختيار مستوى فعلي بعد.
- المدة: لا يوجد فيديو.
- مسارات MP4 النهائية: غير موجودة/لم يتم التحقق منها عبر ffprobe.

## المطلوب لاستكمال التنفيذ
- موافقتك الصريحة على استخدام حساب Kaggle ومفتاح API المجاني، وحفظهما كـ GitHub Secrets باسم `KAGGLE_USERNAME` و`KAGGLE_KEY`؛ لا ترسل المفتاح داخل المحادثة ولا تحفظه في المستودع.
- إكمال خط الصوت العربي والكابشن وتجميع المشاهد والاختبارات قبل فتح PR وفق تعليمات المشروع.
- بعد وصول Workflow إلى الفرع الافتراضي وإضافة الأسرار، يمكن إطلاق أول تشغيل والتحقق من Artifact وffprobe.

لا توجد حتى الآن نتيجة توليد MP4. لا تعتبر تكامل GitHub/Kaggle مختبرًا حتى ينجح تشغيل حقيقي.
